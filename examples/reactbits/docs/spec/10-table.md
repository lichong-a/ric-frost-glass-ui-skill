# 10. 表格与数据页面

### 10.1 基准结构

完整技能表顺序为：**名称、用途、标签、状态、版本、依赖、绑定员工、操作**。根据业务能力在最左侧增加可选复选列。表格外壳为一个完整阅读面，顶部显示筛选后的记录数量，底部显示分页。

使用真实 `<table>` 语义，列头使用 `<th scope="col">`。默认不是电子表格，因此不要无理由增加 ARIA grid 或使每个单元格可聚焦。需要排序时在表头使用有名称的按钮，并以 `aria-sort` 表达排序状态。

| 列 | 宽度策略 | 内容规则 |
|---|---|---|
| 复选框（可选） | 44 px 固定 | 仅 selectable 模式 |
| 名称 | 最小 240 px；约 23% | 图标底 + 名称；重要名称字重 500 |
| 用途 | 最小 280 px；使用主要剩余空间 | 次要文字，一行省略，可查看完整说明 |
| 标签 | 最小 120 px | 最多一至两个 + 其余数量 |
| 状态 | 96 px 左右 | 语义状态胶囊 |
| 版本 | 96 px 左右 | 等宽数字；不要拆开版本号 |
| 依赖 | 120 px 左右 | 无依赖 / 摘要 / 详情入口 |
| 绑定员工 | 96 px 左右 | 数字对齐，可为明确链接 |
| 操作 | 最小 140 px | 编辑按钮 + 更多；不换行 |

这是列宽约束，不是要求所有宽度百分比固定相加。完整模式表格最小宽度约 1240 px；空间不足由表格容器横向滚动。窄屏可以按明确方案隐藏次要列并提供详情，但不能直接截断关键操作。

表头高 44 px，常规行高 52 px；内边距横向 16 px；只使用细水平分割线，不绘制深色纵向网格。长名称和用途默认单行省略，名称旁图标不缩小；可访问的完整内容通过详情、可聚焦展开或文本说明提供。

### 10.2 行状态

| 状态 | 背景 | 其他表现 |
|---|---|---|
| default | 象牙白阅读面 | 细水平分割线 |
| hover | 浅暖米色 | 不改变勾选、不替换字体 |
| selected | 浅茶绿 | 明确的复选状态或选择说明 |
| selected + hover | 保持选中主色，可轻微增强 | selected 优先于普通 hover |
| 键盘聚焦内部操作 | 行背景可轻度强调 | 焦点环位于实际按钮，不把整行误作按钮 |
| disabled item | 专用文字 / 状态说明 | 操作按业务禁用；仍可查看记录 |

选择行、打开详情、编辑和更多菜单是不同动作。行内按钮不能冒泡触发行选择或跳转。仅当前页全选是默认策略；跨页全选必须有明确的二次入口、作用范围和计数。

### 10.3 行操作与性能

“编辑”使用图标 + 文字，更多按钮使用 32 px 点击区并包含记录名称，例如“打开纯文本摘要的更多操作”。菜单通过 Portal 或等价 overlay 管理，不能被表格的 `overflow` 裁掉。

默认分页 10 / 20 / 50 / 100 条，不为第一页几十条数据引入复杂虚拟滚动。大数据模式是否虚拟化由性能测量决定；引入时仍要保留表头、行键、选中状态、可访问内容和稳定行高。滚动时不重复计算每个单元格的模糊或阴影。
