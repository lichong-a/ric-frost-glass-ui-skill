# 5. 字体与图标

### 5.1 字体分工

| 元素 | 字体类型 | 大小 / 行高 | 字重 |
|---|---|---|---|
| 品牌 Agent Wan | 无衬线 | 24 / 32 px | 600 |
| 页面主标题 | 宋体 / 衬线 | 36 / 48 px | 500–600 |
| 窄屏页面主标题 | 宋体 / 衬线 | 28 / 38 px | 500–600 |
| 弹窗主标题 | 宋体 / 衬线 | 24 / 32 px | 500–600 |
| 卡片、浮层分区标题 | 无衬线 | 18 / 26 px | 600 |
| 导航项 | 无衬线 | 15 / 24 px | 400；选中 500 |
| 表格、按钮、输入、菜单 | 无衬线 | 14 / 22 px | 400；重要名称 500 |
| 描述 / 辅助文字 | 无衬线 | 13 / 20 px | 400 |
| 紧凑计数、标签 | 无衬线 | 12 / 18 px | 400–500 |

同一页面正文不要在 14、15、16 px 之间随机跳变。规范以 14 px 数据正文实现 R1 的舒适密度；如果目标设备缩放使整体偏小，可整体切换 15 px 正文并重新截图校准，不允许逐个组件临时加字号。

```css
/* 最终字体变量以 tokens.css 为准；以下展示字体分工。 */
--font-ui: "Inter", "Noto Sans SC", "PingFang SC", "Microsoft YaHei", system-ui, sans-serif;
--font-title: "Noto Serif SC", "Source Han Serif SC", "Songti SC", "STSong", "SimSun", serif;
```

不随包分发未授权字体。目标项目若需要跨系统一致的中文标题，应提供已授权的 WOFF2 字体并固定字重；仅依赖系统回退会产生字形、行宽和换行差异。字体加载失败时仍必须可读；不要为了等字体而隐藏正文。

页面主标题允许约 `0.02em` 的轻微字距；正文和按钮保持默认字距。版本、数量和分页使用 `font-variant-numeric: tabular-nums`。不要给中文正文加大字距。

### 5.2 图标与品牌

使用一个统一的线性图标库，优先沿用项目已有的圆角线性图标；未指定时可采用 Lucide 风格。常规图标 18–20 px，导航 20 px，行图标 18 px，空态 36–40 px；线宽约 1.75–2 px。不得用 emoji 代替操作图标。

名称前的图标底为 36 × 36 px、10 px 圆角，底色使用浅茶绿或浅沙色；图标保持深墨色。图标底属于类别装饰，不应被误作独立按钮。品牌图形以用户正式品牌资产为准；图中四格标志仅作为构图参考，不能从低分辨率截图反复放大。
