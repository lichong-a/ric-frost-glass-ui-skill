# 9. 基础组件视觉规范

所有组件至少考虑 default、hover、active、focus-visible、disabled；有异步行为时再增加 loading，有输入时再增加 invalid、readonly。没有交互的标签和装饰图标不强加 hover。

### 9.1 按钮

| 变体 | 背景与文字 | 使用 |
|---|---|---|
| `primary` | 苔绿底、象牙白字；可有非常轻的纵向明暗 | 导入、创建确认、保存等主要动作 |
| `secondary` | 象牙白半透明底、深墨字、轻边与接触影 | AI 创建、取消、次级入口 |
| `ghost` | 默认透明；hover 出现低对比背景 | 行内编辑、文本操作 |
| `danger-outline` / `danger` | 浅色陶土边，或深陶土底配浅字 | 删除、不可逆危险动作 |
| `warning` | 沙金语义 | 可恢复但会影响使用的停用确认 |
| `icon` | 方形点击区，图标居中 | 搜索、更多、关闭 |

同一操作区通常只有一个 `primary`。R1 中“AI 创建 Skill”为 secondary，“导入 Skill”为 primary。图标与文字间距 8 px；按钮左右内边距 16 px，large 可 20 px。

普通危险入口使用 `danger-outline`，最终确认弹窗可以使用更强的实心 `danger`。它们是同一危险语义的不同强调程度；实际类名和属性映射见 [CSS 接入说明](../../../../CSS_API.md)。

loading 必须保留按钮宽度，显示进度与动作文字，阻止重复提交；禁止只让按钮无限旋转却没有失败出口。disabled 使用专用背景、文字、边界，去掉 hover / active；不要对含文字的整个按钮简单 `opacity: .4`。`aria-disabled` 不会自动阻止事件，行为层必须同步处理。

### 9.2 输入框、搜索与表单

输入高度 40 px，large 48 px；左右 12 px，含前图标时确保文本不压到图标。背景为 `control`，普通边界与装饰白边分开，焦点使用可见的绿色强调。

| 状态 | 必须呈现 |
|---|---|
| default | 字段标签、清晰占位符、稳定边界 |
| focus | 明显焦点线；保持文字和图标清晰 |
| invalid | 陶土边 / 错误图标 + 字段下错误说明，设置 `aria-invalid` |
| readonly | 可聚焦、可选择和复制值；说明只读原因；不是 disabled |
| disabled | 不可编辑，通常不进入 Tab 序列；提供必要的外部原因说明 |
| loading | 就近显示状态，保留输入与已有内容，避免布局跳动 |

字段标签不能只用 placeholder；错误信息不能只以颜色表达。清除按钮必须有“清除搜索”等可访问名称。搜索默认 250 ms 防抖；中文 IME 合成时不提交半截拼音，`compositionend` 后再发起查询。防抖与请求取消 / 竞态处理是两件事，必须同时处理。

多行输入使用相同材料、10 px 圆角和 12 px 内边距，可按内容增长；不要沿用单行固定高度。表单内字段间距 20 px，标签与控件间距 8 px，错误或帮助文字预留合适空间。

### 9.3 选择器、复选与开关

单选下拉触发器显示当前值，菜单选中项使用浅茶绿背景及右侧勾选；hover 与选中仍可辨别。带搜索的选择器按 Combobox 模式实现，不将搜索输入塞进只有 `menuitem` 的普通操作菜单。[W3C Combobox](https://www.w3.org/WAI/ARIA/apg/patterns/combobox/)

多选项用标签显示，标签右侧移除按钮有名称；内容过长时在一至两行范围内显示，超过部分用 `+N` 或数量摘要，不允许工具栏无限变高。单项勾选后默认保留浮层，以便连续选择；“清空”不改变其他筛选字段。

复选框约 18–20 px 视觉尺寸，点击区域符合第 6 节；未选中、选中、部分选中和禁用分别实现。原生 `indeterminate` 属性或等价原语必须与 `aria-checked="mixed"` 语义一致。开关用于立即生效的布尔设置，不能代替表单的多选项；若切换需要异步保存，失败时回滚并反馈。

### 9.4 分段、Tabs 与分页

状态筛选“可用 / 内测 / 已废弃 / 已停用”是单选筛选，选中项为深苔绿、白字；默认项为浅色按钮。不应因外观像 Tabs 就绑定不真实的 `tabpanel`。可使用单选组或互斥的 `aria-pressed` 按钮。

“概览 / 版本记录”切换不同内容面板，使用 Tabs 语义，底部细绿线标识当前页；“列表 / 网格”为视图模式切换，不改变筛选和选中数据。

分页按钮默认 32 px，当前页为深绿；上 / 下一页在边界禁用。页面大小更改和筛选更改后返回第一页。总数与页数来自服务端或当前数据集，禁止由 DOM 行数冒充总记录数。大量页数使用省略页码，不能让顶层布局无限变宽。

### 9.5 标签、徽标与提示

标签内部单行文字，左右 12 px，约 28 px 高；标签可移除时给关闭控件独立可点击区。角标数量超过展示范围时可显示 `99+`，同时提供完整可访问文本。`25`、`50` 仅为示例。

Tooltip 使用稳定深色底和浅字，约 8 px 圆角，最大宽 280 px；提供 hover 与 focus 触发，不能承载必须点击的操作，也不能作为禁用原因的唯一可达渠道。关键业务说明直接显示在页面或表单中。
