# 6. 尺寸、间距与圆角

### 6.1 间距

以 4 px 为基础步长，常用 `4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48`。1 px 边框、2 px 焦点线和根据字体确定的行高不受 4 px 步长限制。

| 场景 | 规范 |
|---|---|
| 页面水平外边距 | 16 px |
| 页面上下外边距 | 8 px |
| 顶栏与工作区间距 | 12 px |
| 左导航与主工作区间距 | 20 px |
| 主工作区内边距 | 20 px；窄屏 16 px |
| 普通内容卡片内边距 | 20 px |
| 浮层内边距 | 菜单 8 px；复合面板 20 px |
| 弹窗内边距 | 24 px；窄屏 20 px |
| 同组控件间距 | 8 px |
| 筛选组 / 操作组间距 | 12 px |
| 标题与描述间距 | 4–8 px；统一使用 Token 中对应档位 |
| 不同内容区间距 | 20–24 px |

### 6.2 尺寸与圆角

| 元素 | 高度 / 尺寸 | 圆角 |
|---|---|---|
| 小按钮 / 紧凑分页 | 32 px | 8–10 px |
| 默认按钮 / 输入 / 选择器 | 40 px | 10 px |
| 页面主要操作 / 顶栏入口 | 48 px | 10–12 px |
| 侧栏导航行 | 44 px | 12 px |
| 标准菜单行 | 最小 40 px，可按内容增长 | 10 px |
| 标签 | 28 px，左右 12 px | 胶囊 |
| 计数徽标 | 最小 28 × 28 px，长数字自适应 | 胶囊 |
| 图标按钮 | 默认 40 × 40 px；行内可 32 × 32 px | 10 px |
| 通用内容面板 / 大浮层 | — | 20 px |
| 侧栏 / 弹窗 | — | 24 px |
| 主工作区外壳 | — | 28 px |

圆角使用组件级 Token，不因容器变宽就无限放大。复选框保留小圆角方形，单选框为圆形。胶囊仅用于标签、徽标、开关轨道等天然需要的元素，默认按钮不改成大胶囊。

触屏上按钮、图标按钮、导航和菜单条目的点击范围采用本项目 **44 × 44 px** 的舒适目标；视觉图标可以较小。此项目值高于 WCAG 2.2 AA 的一般最小尺寸基线，不应把 44 px 误写成所有场景都强制的 AA 数值。[W3C 目标尺寸说明](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html)
