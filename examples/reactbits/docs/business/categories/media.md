# 媒体浏览

仅在需要按场景选型时读本页；精确名称可直接查询单项指南，不顺序读取整个类别。

| 组件 | 什么时候使用 | 什么时候换用其它能力 |
|---|---|---|
| [Carousel](../components/business-carousel.md) | 少量内容按顺序浏览，有前后按钮和当前项提示 | 大量图片浏览用Gallery；复杂动效按需选择现有Carousel |
| [Compare](../components/business-compare.md) | 同一对象的前后图需要可调整分界并支持键盘 | 不相关图片用Gallery，不强行叠加比较 |
| [Gallery](../components/business-gallery.md) | 多张图片需要缩略图选择与前后查看，保持图片描述 | 连续自动展示用Carousel；单张图可直接Image |

选定一个组件后只读它的文档、示例与必要共享符号。
