# ToggleSwitch

业务表单 · `business-toggleswitch` · 中文意图：设置开关 / 立即生效 / 显示偏好

## 1. 什么场景使用

本地二元设置切换立即反映当前状态。

**不适合或优先替代：**外部写入或危险配置仍需要业务授权与失败恢复。

先确认本次任务要解决的业务行为，再选择本组件。普通业务页面优先使用这里的基础能力；只有用户明确要求装饰效果时才追加效果组件。

## 2. 只加载这一项

1. 只读本指南，确认用途与边界。
2. 只读 [src/business/demos/business-toggleswitch.tsx](../../../src/business/demos/business-toggleswitch.tsx)；共享基础有需要才读 [support.tsx](../../../src/business/support.tsx)。
3. 本例若导入 primitives，再定位该文件中被使用的符号，不加载其它示例。样式按需检索 [业务 Token 皮肤](../../../src/business/business.css) 中的对应类。
4. 涉及业务错误、权限、数据或异步行为时才追加对应契约：[05-input](../../contracts/05-input.md)。
5. 预览库使用本项独立 import() 入口；复制到目标项目时也只接入所需组件和直接依赖。

所有实现使用本项目已有 React、原生 HTML 和 CSS。完整交互、类型与回调以当前示例代码为准。

## 3. 本例真实用法

下面来自当前独立示例。默认导出是一个可运行实例；复制后把本地选项、数据与回调接到目标项目已有业务层，不把演示结果当作后端成功。

```tsx
import { useState, useId } from 'react';
import { BusinessDemo } from '../support';

// 场景：立即生效的二元设置；危险或有外部副作用的设置仍需要业务确认。
export default function ToggleSwitchDemo() {
  const id = useId(); const [enabled, setEnabled] = useState(true);
  return <BusinessDemo title="ToggleSwitch · 设置开关" description="开关表示当前本地偏好，切换立即更新显示。"><label className="aw-business-choice" htmlFor={id}><input id={id} className="aw-business-switch" type="checkbox" role="switch" checked={enabled} onChange={event => setEnabled(event.target.checked)} />显示详细摘要</label><p className="aw-business-status" role="status">摘要：{enabled ? '详细' : '简洁'}</p></BusinessDemo>;
}
```

## 4. 接入约束

- 颜色、阅读面、圆角、边界、焦点与阴影使用 Agent Wan Token，业务逻辑留在所属模块。
- 服务端状态、资源归属与动作权限由既有可信业务接口处理；前端输入限制只服务于体验。
- 保留本项键盘、名称、空状态、错误状态和恢复入口，清理拥有的监听、计时器、观察器与对象 URL。
- 文档中的本地数组、文件或短命令只用于示例；不增加未授权的上传、设备访问、外部写入或 shell 执行。
- 减少运动偏好下保留业务操作，仅停用短过渡；不要因为动效偏好关闭必要表单与菜单。
