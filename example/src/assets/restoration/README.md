# Visual restoration assets

The six SVG illustrations in this directory are original artwork authored for this demo restoration on 2026-10-13. They combine authored vector geometry, multicolor gradients and SVG fractal noise. They contain no external images, fonts, scripts, links or embedded third-party material. They are illustrative artwork rather than photographs.

| `chromatic-bloom.svg` | Chromatic Bloom | Dither Veil, image galleries |
| `prismatic-canopy.svg` | Prismatic Canopy | Halftone Reveal, image galleries |

## Effect references

The demos use the repository's locked React Bits implementations without modifying `.upstream`. Official reference page URLs, intended visible behavior, default restoration parameters and asset mapping are recorded in `catalog/visual-restoration.json`. The local artwork intentionally replaces remote photos so these demos do not depend on a third-party image host.
