# 效果、功能、加载与降级

## 1. 保留组件身份

每个组件文档的“必须保留”说明可观察机制。调整茶绿、沙米、墨色、面板圆角和柔影；保留其路径运动、粒子、折射、形变或操作规律。降低饱和度不等于把效果删除。用户已点名某个动态组件或要求全组件示例时，直接实现被要求的效果；普通后台任务只添加需求涉及的效果。

可调范围优先通过实际 Props 实现。源码没有对应 Props 时，在目标项目副本中适配，记录改动；不能伪造一个不存在的参数。业务阅读面保持稳定，强烈光影限制在展示舞台或非关键装饰层。

## 2. 按需取官方实现

交付目录包含自有示例、主题、清单和安装脚本。**官方组件源码不随模板或 ZIP 再分发**，安装后出现在示例项目的 `.upstream/`。组件文档同时给出随包 demo 和安装后的源码路径。

当所选实现尚未准备，在包根运行：

```bash
node scripts/example.mjs setup --component <slug>
```

脚本按本次清单固定版本从官方来源取得所需实现；保留来源与授权文本。网络失败时保留明确安装状态和重试路径，不能用同名空壳冒充可运行组件。阅读源码只打开被选组件及其直接依赖。复用到业务网站前检查项目现有依赖，不要求为一个组件加载全目录。

## 3. 活跃挂载与生命周期

- 组件目录页只渲染索引和封面；进入单项示例才动态 import。可见且启用后再开始持续动画。切换、隐藏或卸载时释放当前效果。
- 清理事件监听、观察器、RAF、定时器与相关 GPU 资源；语音或相机轨道用完即停止。实现是否已清理必须查看实际源码与运行结果。
- 预留固定舞台尺寸与可读加载面，避免资源加载时页面跳动。懒加载失败显示组件名称、原因摘要和重试入口。
- 组件依赖逐项由清单核对；同一依赖复用项目版本。不可仅因关键词判断它实际启用了 WebGL 或设备权限，索引中的 capabilities 是扫描提示。

## 4. 减少运动与触屏

`prefers-reduced-motion: reduce` 下不挂载装饰性持续动画；标题输出完整文本、数字输出真实终值、导航选中直接到位、图像提供静态浏览。只有 CSS 关闭动效不足以停止 Canvas / WebGL，必要时在 React 条件渲染层选择降级。

指针跟随效果只在适用指针设备中启用；触屏使用等价点击或原生控件，不能要求 hover 才能操作。装饰层不拦截点击，不隐藏真实指针，不抢占全局滚动。高位移或眩光的预览提供运行 / 暂停控制。

## 5. WebGL、资源和权限失败

| 情况 | 降级行为 |
|---|---|
| WebGL / WebGPU 不可用或上下文丢失 | 用静态图片、原内容或 Agent Wan 环境渐变保留版面；显示可读状态，不重复无上限重建 |
| GPU、Canvas 模块或依赖加载失败 | 当前示例显示失败和重试，其他目录仍可用 |
| 模型、图像或字体加载失败 | 使用稳定尺寸的替代内容与描述；不隐藏业务文案 |
| 相机、麦克风无权限 | 仅在用户主动点击对应功能后请求；拒绝后保留替代输入 / 图片，并说明状态 |
| 减少透明度或 backdrop-filter 不可用 | 使用 Token 中的稳定底色与可辨边界 |

Aero Shards 与 Shape Waves 原版使用 WebGPU：适配器检查最多等待 1.5 秒，原版渲染最多等待 15 秒首帧 guard。检查失败或原版失效时默认显示可读不可用提示；用户手动选择“运行兼容预览”后才挂载带标记的 Canvas 2D 近似实现，并保留它与原版的差异说明。兼容预览不能作为原版渲染成功的证明。资源重建时取消旧检查并释放旧资源。

## 6. Agent UI 的真实状态

Thought Line、Call Chip、Status Mark、Lattice Loader、Refine Frame、Voice Pill 和 Prompt Bar 只呈现业务层明确提供的公开状态、步骤摘要、内容与计时。不要编造模型隐藏推理、工具成功或录音结果。演示计时/状态必须标为示例，生产中以真实任务事件为准。

## 7. 检查范围

确认加载前后、重试、卸载、窄屏、键盘、触屏、减少运动和不可用环境；行为验收按 [可访问性与动效规则](spec/13-a11y-motion.md) 和对应契约。是否完成浏览器视觉和真实交互检查分别记录，不能以 Token 或构建校验代替。
