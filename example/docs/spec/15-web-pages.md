# 15. 扩展到其他 Web 页面

用户要求创建其他页面时，保持材质、字体、色彩、圆角与交互基础不变，按信息类型选择布局。

| 页面类型 | 应沿用的模式 | 允许调整 |
|---|---|---|
| 工具 / 连接器 / 插件列表 | R1 的页面头、筛选和表格 | 列、筛选项、状态与业务操作 |
| Agent 卡片列表 | 同一 AppShell、工具栏、霜玻璃卡片 | 卡片网格列数、摘要、业务状态 |
| 详情页面 | 页面头 + 概览 / 版本 / 日志 Tabs + 阅读面 | 内部分区，不重新设计导航 |
| 设置页面 | 宋体主标题、清晰表单、固定动作语义 | 单列 / 双列表单，分区标题无衬线 |
| 运行日志 / 审计 | 稳定浅色数据面、同一表格与筛选 | 更高数据密度需统一切换 compact 变体 |
| 概览页 | 少量指标卡 + 清晰图表阅读面 | 指标和图表组合，图表色仍用低饱和语义色 |
| 公开 Web 页面 | 相同背景、字体分工、表面和按钮 | 按内容设置阅读宽度；不机械携带管理侧栏 |

没有参考的页面可以按这些规则组合，但不能称为对某张不存在的页面逐像素复刻。图表不加背景模糊滤镜，不让透明网格干扰数据线；实际图表和业务路由仅在用户要求时实现。
