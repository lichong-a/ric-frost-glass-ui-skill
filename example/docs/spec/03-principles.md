# 3. 风格原则与不可变项

### 3.1 视觉优先级

先复现 **框架比例与信息密度**，再复现 **背景、透明度与表面层次**，然后校准 **字体、间距、颜色与控件状态**。不能仅用一套绿色按钮代替整套设计。

| 维度 | 必须呈现 |
|---|---|
| 气质 | 安静、克制、自然、专业的管理后台 |
| 环境色 | 左侧灰茶绿，右侧暖沙米，中部象牙白；大尺度柔和色团 |
| 内容层 | 深墨绿文字，稳定的浅色阅读面，轻微背景透色 |
| 形状 | 少量统一圆角档位；矩形控件保留矩形结构 |
| 深度 | 背景、框架、内容、浮层有明确层次，阴影向下且柔和 |
| 强调 | 主动作与当前页使用苔绿；警告、错误用克制的沙金和陶土色 |
| 装饰 | 由颜色、材料与字体完成；不增加具象中式装饰 |

### 3.2 禁止项

- 禁止高饱和翠绿、紫蓝渐变、霓虹、彩虹折射边、金属反光和大面积纯黑阴影。
- 禁止将所有表面改成实心纯白卡片，或将所有表面设置成相同透明度。
- 禁止对包含内容的容器使用 `filter: blur()`、整体降低 `opacity` 或截图文字。
- 禁止全页宋体、书法体、超大展示板标题或大幅压缩业务表格密度。
- 禁止每个按钮、表格单元格和标签分别开启背景模糊。
- 禁止把普通 hover、持久 selected、键盘 focus、disabled 合并成同一状态。
- 禁止用右侧主导航替换 R1 的左侧导航。
- 禁止加入山水、竹子、宣纸毛边等参考图没有的具象元素。
