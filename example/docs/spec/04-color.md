# 4. 颜色与语义

### 4.1 基础色与文字

以下为本版本的实现值。R1 主按钮局部呈现色约为 `#52604E`；其余透明表面的像素颜色包含背景混色，不能直接作为源 RGBA。配色结构优先于单个取色点。

| 用途 | 基准值 | 使用限制 |
|---|---|---|
| 页面基底 | `#E8E4D7` | 承载环境渐变 |
| 象牙白 | `#FAF7F0` | 玻璃表面与稳定阅读面 |
| 主要文字 | `#1F2D26` | 页面标题、名称、正文、图标 |
| 次要文字 | `#5C6259` | 描述、非关键列、字段说明 |
| 辅助文字 | `#64695F` | 占位符、时间、统计；仍需验证可读性 |
| 主操作 | `#52604E` | 导入、保存、主要确认、当前页 |
| 主操作 hover | `#465642` | 变深，不变艳 |
| 主操作 active | `#3F4E3B` | 按下状态 |
| 强可辨边界 | `#77806F` | 输入、复选等需要辨认的交互边界 |

CSS 语义变量使用 `--aw-color-text-primary`、`--aw-color-text-secondary`、`--aw-color-text-muted`、`--aw-color-action-primary`、`--aw-color-action-hover`、`--aw-color-action-active`。页面不得绕过 Token 添加近似绿或近似米色。

### 4.2 状态色

| 语义 | 浅背景 | 文字 / 图标 | 示例 |
|---|---|---|---|
| 成功 / 可用 / 低风险 | `#E0E6D2` | `#405239` | 可用、已校验、低风险 |
| 警告 / 待确认 | `#F4E5C8` | `#81591F` | 待审核、中风险、未扫描 |
| 错误 / 高风险 | `#F1DFD5` | `#8E4C39` | 扫描失败、导入失败、高风险 |
| 中性信息 | `#E3E9E4` | `#4D6465` | 处理中、信息提示 |

可用、内测、已废弃、已停用是业务生命周期状态；低风险、中风险、高风险、禁止使用是风险状态；导入中、扫描中、失败是任务状态。三组状态不得复用一个枚举。禁止将“导入成功”自动呈现为“可以启用”。

内容标签使用 `sage / sand / stone` 等语义类别色，同一类别颜色固定。标签不是状态灯，不应把每个标签渲染成不同鲜艳颜色。选中状态还必须通过勾选、导航竖条、当前页或文本说明表达。

### 4.3 对比度规则

普通文字以实际合成背景上的 **4.5:1** 为验收目标；大文字可按 WCAG 的定义使用 **3:1**，不能仅因“它是标题”就降低要求。需要用于辨识控件或状态的非文字图形应按适用的非文字对比要求检查。玻璃的白色装饰边不代替交互边界。参见 [W3C 文字对比](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html) 与 [非文字对比](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html)。

`validate-tokens.mjs` 的颜色检查只证明脚本列出的纯色组合或显式混合样本，不代表整张玻璃页面通过可访问性验收。实现后还要在背景最深、最浅处检查小文字、占位符、表头和选中项。
