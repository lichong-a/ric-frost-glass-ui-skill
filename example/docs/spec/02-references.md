### 2.1 统一规则

1. 页面信息密度以 R1 为准；R2–R4 是组件展示板。
2. 参考图的绿色与米色差异主要通过背景透色产生，不为每张图新建一套白色。
3. R1 表格默认不显示复选列；R4 的复选列是 `selectable` 模式，按业务开启。
4. 标题字体统一为少量宋体；菜单、表格、按钮、数字保持无衬线。
5. 浮层双层亮边统一为外部细亮边与内部高光，避免每张卡片都堆叠厚描边。
6. 待办数量、角色名、版本号、表格内容来自业务数据；禁止将图片数值固化为逻辑常量。
