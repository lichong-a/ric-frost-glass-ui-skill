# 13. 交互、可访问性与降级

### 13.1 键盘和语义

入口必须是原生按钮、链接或成熟的可访问原语。菜单触发器标记展开状态与关联关系，Enter / Space 打开，菜单内使用方向键，Escape 关闭并返回触发器；不劫持普通文本输入的光标和编辑键。[W3C Menu Button](https://www.w3.org/WAI/ARIA/apg/patterns/menu-button/)

普通非模态内容面板允许 Tab 正常离开，不像模态框那样锁住焦点；模态框内焦点受控，关闭后返回合理位置。选择器按它的实际结构使用 Combobox 或 Listbox 语义，不把操作菜单、搜索列表和复杂表单面板一律标记为 `menu`。[W3C Listbox](https://www.w3.org/WAI/ARIA/apg/patterns/listbox/)

图标按钮提供可访问名称；纯装饰图标设置 `aria-hidden`。页面只有一个主 h1，标题层级连续。焦点环使用高对比内外两层或等价效果，不被圆角裁切；不能仅在鼠标 hover 时显示关键动作。

### 13.2 动效

普通业务控件采用短促的自然变化：颜色与接触影约 120 ms，控件状态约 160 ms，浮层进入约 180 ms、退出约 120 ms，对话框约 200 ms。使用克制的 ease-out，浮层位移不超过 4 px；默认不添加弹跳、旋转展开或持续呼吸。

用户明确选择动效组件或要求效果示例时，保留该组件的核心机制，包括必要的弹性、旋转、粒子、持续运动或物理效果；按需挂载并限制在对应展示区域。其形变与节奏以单组件实际用法为准，颜色、阅读面和业务语义仍遵循本规范。不要用普通控件的 4 px 限制消除用户点名的效果，也不要据此给所有业务控件增加动画。

包含 `backdrop-filter` 的面板不对整个面板做 opacity 动画；可使用轻微位移，或将装饰表面与内容动画明确分层并验证背景采样。遵从 `prefers-reduced-motion`，取消非必要位移与骨架扫光。骨架可以保持静态，界面不依赖动画传达完成状态。

### 13.3 内容边界

必须验证 40 个中文字的技能名、80 字用途、长英文标识、长租户名、多标签、0 条记录和多页记录。长文本不能把更多按钮挤出视口；工具栏和弹窗不能因局部撑宽而让整页横滚。

动态操作使用稳定实体 ID，不用表格数组索引标识对象。改变租户、空间、筛选或请求参数时要防止旧请求覆盖新上下文；具体契约见 `COMPONENT_CONTRACTS.md`。

### 13.4 主题范围

v1.0 的参考与色值覆盖浅色霜玻璃主题。R2 中出现的“深色 / 跟随系统”仅证明有主题选择入口，未提供暗色视觉基准。不得把未经设计的自动反色称为同等保真的暗色主题。只交付浅色的产品可以暂不展示未实现选项；已有暗色系统则保留现有能力并明确它不属于本轮视觉复刻基准。
