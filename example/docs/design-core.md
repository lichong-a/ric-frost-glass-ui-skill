# Agent Wan 核心视觉约束

本页是首次加载的短约束。任务需要某一类组件时再读取对应章节，不在此复制完整 Token。

- **保留外观层次**：茶绿 / 沙米的低频环境透色，象牙白阅读面，深墨绿文字，少量宋体主标题。圆角、细亮边、柔影与不同厚度的霜玻璃共同构成风格。
- **页面布局**：顶栏独占整行，Logo 左，待办 / 租户空间 / 个人信息右；左导航、右工作区。完整页面图确定布局与信息密度，组件板只补充外观。
- **数值来源**：[tokens.json](../../tokens.json) 为权威；只检索当前使用的语义变量。主色、圆角、透明度和阴影不得在组件里另建近似值。若 GPU 参数需要数值色，复用示例中的主题映射或在运行时解析 Token，不能把 `var(...)` 直接传给不支持 CSS 变量的着色器 API。
- **功能 / 效果 / 皮肤**：功能来自目标项目及基础契约；所选组件提供对应的效果机制；Agent Wan 提供配色、排版、阅读面和交互边界。三者分别保持，不用同一个悬停效果替代所有组件。
- **安静与展示并存**：业务页面按需求选择效果；组件展示允许演示每个完整效果。高运动、指针跟随、Canvas / WebGL 与物理效果仅在活跃示例或明确需要的位置运行。
- **文字保持可读**：禁止对含文字的容器整体降低透明度，禁止通过整块 `filter: blur()` 制造玻璃。文字揭示效果短暂模糊时仍保留可访问的完整文案，并在减少运动时直接显示终态。
- **保留交互质量**：hover、selected、focus、disabled、loading 分开；所有变形控件仍有稳定可点击范围、键盘路径与可访问名称。
