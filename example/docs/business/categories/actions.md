# 按钮与操作

5 个组件。动作入口、提交、快捷操作与撤销。每项只有一个主用途；来源与组合／微交互作为标签保留。没有精确名称或需要同类比较时才读本页，选定一项后停止扩展。

| 组件 | 用途 | 来源与标签 |
|---|---|---|
| [Button](../components/business-button.md) | 执行明确动作，提供主次、危险、禁用和反馈状态 | business、业务基础、business-action、业务动作、原生 React |
| [ButtonGroup](../components/business-buttongroup.md) | 相邻展示关系明确的动作，并独立表达每项语义 | business、业务基础、business-action、业务动作、原生 React |
| [SpeedDial](../components/business-speeddial.md) | 主入口展开少量相关快捷动作，触屏与键盘都可选 | business、业务基础、business-action、业务动作、原生 React |
| [Toolbar](../components/business-toolbar.md) | 围绕当前内容组织少量相关动作和筛选 | business、业务基础、business-panel、布局与流程、原生 React |
| [SplitButton](../components/business-splitbutton.md) | 一个常用主动作与少量替代动作并存 | business、业务基础、business-action、业务动作、原生 React |

选定一个组件后只读它的指南、示例与实际依赖；返回 [任务路由](../task-router.md)。
