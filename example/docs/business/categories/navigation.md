# 导航与菜单

7 个组件。页面导航、命令查找与菜单选择。每项只有一个主用途；来源与组合／微交互作为标签保留。没有精确名称或需要同类比较时才读本页，选定一项后停止扩展。

| 组件 | 用途 | 来源与标签 |
|---|---|---|
| [Tabs](../components/business-tabs.md) | 同一位置展示互斥内容视图，支持方向键与选中面板关联 | business、业务基础、business-panel、布局与流程、原生 React |
| [Breadcrumb](../components/business-breadcrumb.md) | 展示当前层级位置并提供上级导航目标 | business、业务基础、business-navigation、业务导航、原生 React |
| [ContextMenu](../components/business-contextmenu.md) | 操作依赖当前对象，通过右键和可见按钮都能打开 | business、业务基础、business-navigation、业务导航、原生 React |
| [Menu](../components/business-menu.md) | 一组相关动作通过菜单选择，保留禁用与键盘状态 | business、业务基础、business-navigation、业务导航、原生 React |
| [NavigationMenu](../components/business-navigationmenu.md) | 页面或模块之间导航，有清晰的当前项和目标 | business、业务基础、business-navigation、业务导航、原生 React |
| [Sidebar](../components/business-sidebar.md) | 工作区需要持续的模块导航与可收起侧栏 | business、业务基础、business-navigation、业务导航、原生 React |
| [CommandMenu](../components/business-commandmenu.md) | 很多动作需要统一搜索、方向键选择和Enter触发 | business、业务基础、business-navigation、业务导航、原生 React |

选定一个组件后只读它的指南、示例与实际依赖；返回 [任务路由](../task-router.md)。
