# 媒体与轮播

3 个组件。图片、图集、轮播、模型与媒体比较。每项只有一个主用途；来源与组合／微交互作为标签保留。没有精确名称或需要同类比较时才读本页，选定一项后停止扩展。

| 组件 | 用途 | 来源与标签 |
|---|---|---|
| [Carousel · 基础轮播](../components/business-carousel.md) | 少量内容按顺序浏览，有前后按钮和当前项提示 | business、业务基础、business-media、媒体浏览、原生 React |
| [Compare](../components/business-compare.md) | 同一对象的前后图需要可调整分界并支持键盘 | business、业务基础、business-media、媒体浏览、原生 React |
| [Gallery](../components/business-gallery.md) | 多张图片需要缩略图选择与前后查看，保持图片描述 | business、业务基础、business-media、媒体浏览、原生 React |

选定一个组件后只读它的指南、示例与实际依赖；返回 [任务路由](../task-router.md)。
