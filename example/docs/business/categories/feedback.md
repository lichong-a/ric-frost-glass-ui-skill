# 状态与反馈

10 个组件。等待、进度、通知与结果状态。每项只有一个主用途；来源与组合／微交互作为标签保留。没有精确名称或需要同类比较时才读本页，选定一项后停止扩展。

| 组件 | 用途 | 来源与标签 |
|---|---|---|
| [Message](../components/business-message.md) | 反馈与具体字段或区域相关，需要常显或可关闭 | business、业务基础、business-feedback、状态反馈、原生 React |
| [Toast](../components/business-toast.md) | 操作完成后给出非阻断反馈，可关闭且不会抢焦点 | business、业务基础、business-feedback、状态反馈、原生 React |
| [Avatar](../components/business-avatar.md) | 显示人物或团队识别信息，并提供无图片的姓名缩写 | business、业务基础、business-feedback、状态反馈、原生 React |
| [Badge](../components/business-badge.md) | 给对象补充短数量或新状态，文本含义仍可读 | business、业务基础、business-feedback、状态反馈、原生 React |
| [Chip](../components/business-chip.md) | 紧凑展示一个可选或可移除的对象，移除有可访问名称 | business、业务基础、business-feedback、状态反馈、原生 React |
| [MeterGroup](../components/business-metergroup.md) | 多个部分组成总量，需要同时显示数值、标签与比例 | business、业务基础、business-feedback、状态反馈、原生 React |
| [ProgressBar](../components/business-progressbar.md) | 已有可信完成比例时显示有界进度与状态 | business、业务基础、business-feedback、状态反馈、原生 React |
| [ProgressSpinner](../components/business-progressspinner.md) | 操作正在等待且没有可信百分比，提供文字与完成/取消路径 | business、业务基础、business-feedback、状态反馈、原生 React |
| [Skeleton](../components/business-skeleton.md) | 已知内容布局但数据尚未到达，预留稳定尺寸 | business、业务基础、business-feedback、状态反馈、原生 React |
| [Tag](../components/business-tag.md) | 用文字和受控颜色表达短状态或分类 | business、业务基础、business-feedback、状态反馈、原生 React |

选定一个组件后只读它的指南、示例与实际依赖；返回 [任务路由](../task-router.md)。
