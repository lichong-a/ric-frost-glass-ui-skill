# 布局与流程

6 个组件。工作区分隔、内容布局与顺序流程。每项只有一个主用途；来源与组合／微交互作为标签保留。没有精确名称或需要同类比较时才读本页，选定一项后停止扩展。

| 组件 | 用途 | 来源与标签 |
|---|---|---|
| [Divider](../components/business-divider.md) | 视觉和语义分隔不同内容组，保持分隔方向与标签 | business、业务基础、business-panel、布局与流程、原生 React |
| [ScrollArea](../components/business-scrollarea.md) | 长内容在固定区域内滚动，保留键盘与可见滚动条 | business、业务基础、business-panel、布局与流程、原生 React |
| [Splitter](../components/business-splitter.md) | 两个工作区需要用户调整比例，保留最小尺寸和键盘 | business、业务基础、business-panel、布局与流程、原生 React |
| [Stepper](../components/business-stepper.md) | 任务有明确顺序与当前步骤，前进回退由实际状态驱动 | business、业务基础、business-panel、布局与流程、原生 React |
| [Fluid](../components/business-fluid.md) | 容器中的控件随可用宽度伸缩，保留合理最小尺寸 | business、业务基础、business-utility、基础辅助、原生 React |
| [StyleClass](../components/business-styleclass.md) | 一个局部状态需要控制类名或可见性，由React状态驱动 | business、业务基础、business-utility、基础辅助、原生 React |

选定一个组件后只读它的指南、示例与实际依赖；返回 [任务路由](../task-router.md)。
