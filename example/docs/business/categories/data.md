# 数据与文件

11 个组件。记录、层级、列表、文件与结果浏览。每项只有一个主用途；来源与组合／微交互作为标签保留。没有精确名称或需要同类比较时才读本页，选定一项后停止扩展。

| 组件 | 用途 | 来源与标签 |
|---|---|---|
| [DataTable](../components/business-datatable.md) | 结构化记录需要列比较、搜索、排序和分页 | business、业务基础、business-data、数据与文件、原生 React |
| [DataView](../components/business-dataview.md) | 同一批记录在列表和网格中浏览，保持选择与筛选 | business、业务基础、business-data、数据与文件、原生 React |
| [OrderList](../components/business-orderlist.md) | 单个列表中的顺序本身有意义，用户调整优先级 | business、业务基础、business-data、数据与文件、原生 React |
| [OrganizationChart](../components/business-organizationchart.md) | 展示可展开的上下级组织或责任关系并选择节点 | business、业务基础、business-data、数据与文件、原生 React |
| [Paginator](../components/business-paginator.md) | 有界结果集需要前后页和每页数量选择 | business、业务基础、business-data、数据与文件、原生 React |
| [PickList](../components/business-picklist.md) | 用户在可选与已选集合之间移动对象，支持移除与全选 | business、业务基础、business-data、数据与文件、原生 React |
| [Timeline](../components/business-timeline.md) | 按时间顺序呈现已经发生的事件或流程进展 | business、业务基础、business-data、数据与文件、原生 React |
| [Tree](../components/business-tree.md) | 浏览可展开层级并选择节点，保持键盘与选中状态 | business、业务基础、business-data、数据与文件、原生 React |
| [TreeTable](../components/business-treetable.md) | 层级记录需要同时比较多列数据并展开子记录 | business、业务基础、business-data、数据与文件、原生 React |
| [FileUpload](../components/business-fileupload.md) | 用户选择本地文件，验证类型大小数量并能逐项移除 | business、业务基础、business-data、数据与文件、原生 React |
| [Terminal](../components/business-terminal.md) | 产品确有受限文本命令入口时保留输入、历史和结果 | business、业务基础、business-utility、基础辅助、原生 React |

选定一个组件后只读它的指南、示例与实际依赖；返回 [任务路由](../task-router.md)。
