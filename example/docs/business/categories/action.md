# 业务动作

仅在需要按场景选型时读本页；精确名称可直接查询单项指南，不顺序读取整个类别。

| 组件 | 什么时候使用 | 什么时候换用其它能力 |
|---|---|---|
| [Button](../components/business-button.md) | 执行明确动作，提供主次、危险、禁用和反馈状态 | 导航目标用链接；状态选择用ToggleButton |
| [ButtonGroup](../components/business-buttongroup.md) | 相邻展示关系明确的动作，并独立表达每项语义 | 页面主导航用NavigationMenu；不堆无关动作 |
| [SpeedDial](../components/business-speeddial.md) | 主入口展开少量相关快捷动作，触屏与键盘都可选 | 大量命令用CommandMenu；关键动作应直接可见 |
| [SplitButton](../components/business-splitbutton.md) | 一个常用主动作与少量替代动作并存 | 无默认动作的全部候选使用Menu |

选定一个组件后只读它的文档、示例与必要共享符号。
