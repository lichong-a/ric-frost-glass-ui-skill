# 卡片与面板

4 个组件。对象卡片、阅读面与内容面板。每项只有一个主用途；来源与组合／微交互作为标签保留。没有精确名称或需要同类比较时才读本页，选定一项后停止扩展。

| 组件 | 用途 | 来源与标签 |
|---|---|---|
| [Accordion](../components/business-accordion.md) | 独立内容段按需展开，触发按钮关联可见区域 | business、业务基础、business-panel、布局与流程、原生 React |
| [Card](../components/business-card.md) | 将一个对象的标题、摘要与相关动作组合在阅读面 | business、业务基础、business-panel、布局与流程、原生 React |
| [Panel](../components/business-panel.md) | 一个有标题的内容区需要可选展开收起与局部动作 | business、业务基础、business-panel、布局与流程、原生 React |
| [Collapsible](../components/business-collapsible.md) | 一个内容块独立展开收起，按钮关联受控区域 | business、业务基础、business-panel、布局与流程、原生 React |

选定一个组件后只读它的指南、示例与实际依赖；返回 [任务路由](../task-router.md)。
