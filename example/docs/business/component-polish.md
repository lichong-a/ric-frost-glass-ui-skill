# 业务组件样式、交互与参数整合

本次修复 19 项业务示例，以现有功能、自然色 Token 和组件私有 CSS Modules 为基线。原组件 ID、用途分类和独立加载路径保持可达；作者模板、参数定义、当前用法与接入指南同步生成。

## 样式失效原因

旧示例把 Button 与 DemoLayout 的 CSS Module 导出展开合并。DemoLayout 中三条分页/顶栏规则引用 `.aw-button`，因此也导出同名键；后展开的布局模块覆盖了 Button 的真正作用域类。实际 Vite 转换和回归测试复现了错误映射，删除布局模块中越界的按钮引用后测试通过。该修复同时恢复其它旧调用方对按钮自己样式的引用，不增加全局按钮规则。

新示例直接使用 Button、明确的原生控件类或组件专属叶组件。Button 的 `ghost` 类型选项与原本已有的透明样式对应，默认按钮及原 API 用法仍有效。菜单继续使用不透明 ivory 阅读面。

## 参数联动回归

整合审核发现并修复了四类问题，修复前后的回归记录区分于视觉验收：

- DataTable 与 Paginator 的记录切片、范围文字和 Pager 都使用同一 `pagerState`；外部参数变化也通过实际 setter 同步有效页码/容量。每页数量绑定真实状态，数据总数保留源码中的派生表达式与完整 API，不独立覆盖。
- CommandMenu 每次渲染按当前结果计算有效选中项，外部 DIY 查询/分类变化不会留下越界索引。演示分类只接受实际四项；独立 CommandTabs 也有安全焦点回退。
- OrderList 的编辑数据按 `uniqueBy: id` 校验，重复 ID 在配置派发前整体拒绝，保留最后有效顺序，不改写任务身份。
- 实际 CSS Module 合并必须保留按钮组件自己的命名空间；回归在删除布局模块的越界引用前失败、修复后通过。
