# 弹层与辅助

10 个组件。对话框、提示、浮层与焦点辅助。每项只有一个主分类，原来源与组合／微交互作为用途标签保留。

| 组件 | 用途 | 来源与标签 |
|---|---|---|
| [Warm Tooltip](../components/warm-tooltip.md) | 第一项延迟提示后相邻项更快出现 | react-bits、React Bits、micro、微交互、弹层与辅助 |
| [Dialog](../business/components/business-dialog.md) | 任务需要临时阻断背景并收集确认或有限输入 | business、业务基础、business-overlay、弹层与焦点、原生 React |
| [Drawer](../business/components/business-drawer.md) | 不离开当前列表即可查看或编辑较多详情 | business、业务基础、business-overlay、弹层与焦点、原生 React |
| [OverlayManager](../business/components/business-overlaymanager.md) | 多个临时浮层需要明确堆叠、最后打开先关闭和焦点恢复 | business、业务基础、business-overlay、弹层与焦点、原生 React |
| [Popover](../business/components/business-popover.md) | 锚点旁呈现少量可操作内容，Escape与外部点击可关闭 | business、业务基础、business-overlay、弹层与焦点、原生 React |
| [Tooltip](../business/components/business-tooltip.md) | 简短说明在hover或focus出现，不承载必须完成的操作 | business、业务基础、business-overlay、弹层与焦点、原生 React |
| [FocusTrap](../business/components/business-focustrap.md) | 临时任务区需要焦点限制，并能退出和恢复触发点 | business、业务基础、business-utility、基础辅助、原生 React |

| [Portal](../business/components/business-portal.md) | 浮层需要挂到当前文档指定位置，保留主题与生命周期 | business、业务基础、business-utility、基础辅助、原生 React |
| [VisuallyHidden](../business/components/business-visuallyhidden.md) | 补充给辅助技术的名称或说明，视觉布局不显示它 | business、业务基础、business-utility、基础辅助、原生 React |
