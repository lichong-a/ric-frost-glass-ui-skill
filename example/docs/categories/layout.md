# 布局与流程

7 个组件。工作区分隔、内容布局与顺序流程。每项只有一个主分类，原来源与组合／微交互作为用途标签保留。

| 组件 | 用途 | 来源与标签 |
|---|---|---|
| [Stepper](../components/stepper.md) | 步骤状态与内容切换保持同步并可回退 | react-bits、React Bits、components、组合组件、布局与流程 |
| [Divider](../business/components/business-divider.md) | 视觉和语义分隔不同内容组，保持分隔方向与标签 | business、业务基础、business-panel、布局与流程、原生 React |
| [ScrollArea](../business/components/business-scrollarea.md) | 长内容在固定区域内滚动，保留键盘与可见滚动条 | business、业务基础、business-panel、布局与流程、原生 React |
| [Splitter](../business/components/business-splitter.md) | 两个工作区需要用户调整比例，保留最小尺寸和键盘 | business、业务基础、business-panel、布局与流程、原生 React |
| [Stepper](../business/components/business-stepper.md) | 任务有明确顺序与当前步骤，前进回退由实际状态驱动 | business、业务基础、business-panel、布局与流程、原生 React |
| [Fluid](../business/components/business-fluid.md) | 容器中的控件随可用宽度伸缩，保留合理最小尺寸 | business、业务基础、business-utility、基础辅助、原生 React |
| [StyleClass](../business/components/business-styleclass.md) | 一个局部状态需要控制类名或可见性，由React状态驱动 | business、业务基础、business-utility、基础辅助、原生 React |
