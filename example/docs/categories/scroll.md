| [Scroll Velocity](../components/scroll-velocity.md) | 文字移动速度随滚动速度变化 | react-bits、React Bits、text-animations、文字动画、滚动与转场 |
| [Scroll Expand](../components/scroll-expand.md) | 圆角媒体框随滚动扩展到全幅 | react-bits、React Bits、animations、动画效果、滚动与转场 |
| [Halftone Reveal](../components/halftone-reveal.md) | 图片网点在指针附近扩张并显露图像 | react-bits、React Bits、animations、动画效果、滚动与转场、按需挂载 |
